# 跨境选品示例知识文档

> 这是一份**示例文档**，用来验证「我的知识库」的检索与问答效果。
> 把它上传到知识库后，可以直接在对话里问：「按照我的知识库，新手做亚马逊美国站应该按什么标准选品？」
> 你可以随意修改、替换成自己的真实资料。

## 一、选品总原则

1. **先算利润，再谈需求。** 一个需求再大、利润率低于 25% 的品，做起来也只是给平台和物流打工。
2. **需求要能被验证，而不是被想象。** 用平台搜索量、类目 BSR、竞品评论增速验证，不靠"我觉得会火"。
3. **竞争要能被量化。** 首页竞品评论数、上架时间、价格带、卖家数量，决定新品有没有切入点。
4. **合规是生死线，不是加分项。** 认证、侵权、平台禁售类目，任何一条踩中都会导致下架、扣款甚至封店。
5. **小而轻优先。** 同样利润率下，重量轻、体积小、不易碎、无售后的品，长期现金流更稳。

## 二、利润模型

### 2.1 单品利润公式

```
毛利 = 售价 − 采购成本 − 头程物流 − 平台佣金 − FBA/尾程配送费 − 广告费 − 退货损耗 − 其他（仓储/税费）
净利率 = 毛利 ÷ 售价
```

经验阈值（美国站、FBA、非大件）：

| 指标 | 健康区间 | 警戒线 |
| --- | --- | --- |
| 净利率 | ≥ 30% | < 20% 不建议 |
| 广告费占售价 | 8%–12% | > 15% 危险 |
| 物流成本占售价 | 10%–15% | > 20% 建议放弃 |
| 退货率 | < 5% | > 10% 需要重算 |
| 采购成本占售价 | ≤ 25% | > 35% 抗风险能力差 |

### 2.2 新手起步资金

- 首批备货 200–500 件为常见起点，单 SKU 压货金额建议不超过总预算的 30%。
- 预留 3 个月现金流：广告测试、补货、退货、仓储都要钱。
- 不要把全部预算押在一个"爆款判断"上，至少准备 2–3 个候选品做小批量测试。

## 三、需求验证

1. **搜索量**：核心关键词月搜索量 ≥ 5000 且近 12 个月趋势不持续下滑。
2. **竞品结构**：首页至少 3–5 个评论数 < 200 的新品能站住，说明新品有入场机会；如果首页全是 5000+ 评论的老链接，谨慎。
3. **价格带**：主流成交价 $15–$45 是新手较稳的区间；低于 $10 利润被物流吃掉，高于 $80 需要品牌与售后支撑。
4. **评价痛点**：抓 20–50 条 3 星及以下评论，归纳高频差评词；能解决其中一个痛点，就是差异化机会。
5. **季节性**：用 Google Trends / 平台搜索趋势看是否有明显旺季；季节性强的品要按旺季倒推备货与上架时间。

## 四、竞争分析

- **评论壁垒**：头部链接评论数 × 星级 = 信任壁垒；新品靠"解决痛点 + 更优图片 + 更合理价格"切入。
- **卖家结构**：同类目中国卖家占比高、价格战激烈时，优先找细分场景（人群、尺寸、材质、套装）。
- **专利与侵权**：设计专利、外观专利、商标、版权（卡通形象/名人肖像）必须查；不确定就不做。
- **变体策略**：能做颜色/尺寸/套装变体的品，评论与流量可以复用，但要控制 SKU 数量，避免库存分散。

## 五、平台差异（美国站为主）

- **亚马逊**：重产品页质量、评论、FBA 时效；广告是必需品，新品期 ACOS 高是正常的，关键看自然排名是否爬升。
- **TikTok Shop**：内容驱动，适合可视化强、单价低、冲动消费的品；供应链要能承接爆单与快速补货。
- **Temu**：极致性价比，平台主导定价，适合工厂型卖家清产能；品牌溢价空间小。
- **独立站**：适合有品牌故事、复购、溢价能力的品；获客成本高，需要内容与投放能力。

## 六、物流与供应链

1. **头程**：海运 25–35 天（成本低）、空运 7–10 天（成本高）、快递 3–5 天（急补货）。新品首批常走海运 + 少量空运补样。
2. **尾程**：美国 FBA 配送费按尺寸分段；轻小件（< 500g、体积小）配送费优势明显。
3. **包装**：在满足防护的前提下压缩体积重，包装设计要计入成本。
4. **供应商**：至少 2 家备选；打样 2–3 次确认质量；确认起订量、交期、是否支持贴标与验货。
5. **库存周转**：新品期以周为单位看销量与库存天数，断货会掉排名，滞销会压现金。

## 七、合规红线（美国站）

- **认证**：儿童产品需 CPC，电子产品需 FCC，食品接触材料需 FDA 相关合规，化妆品/膳食补充剂门槛更高。
- **禁售/限售**：侵权品、危险品、医疗器械、部分动植物制品等不要碰。
- **标签**：成分、警示语、制造商/责任人信息要齐全；美国站注意各州法规差异（如加州 65 号提案）。
- **税务**：了解销售税代扣代缴规则；欧盟市场还需 VAT、GPSR 责任人信息、CE 等。

## 八、常见失败原因

1. 只看需求不看竞争，进入红海价格战。
2. 利润模型漏算广告、退货、仓储，实际亏损。
3. 侵权/认证问题导致下架，库存变成死货。
4. 供应链断货，排名掉下去后无法恢复。
5. SKU 铺太多，每个都备货不足，广告预算被摊薄。
6. 图片与文案不符合平台规范，转化率上不去。

## 九、可复用关键词模板

- 选品调研：`<品类> + 差评 / 痛点 / 对比 / 测评`
- 需求验证：`best <品类> for <场景>`、`<品类> alternatives`
- 竞争分析：`<品类> brand`、`<品类> patent`、`<品类> recall`
- 合规排查：`<品类> FDA / FCC / CPC / CE / GPSR`

## 十、一页纸检查清单

- [ ] 利润率算过三遍（含广告/退货/仓储）
- [ ] 关键词搜索量与趋势确认
- [ ] 首页竞品评论数与新品存活情况确认
- [ ] 20 条以上差评痛点归纳
- [ ] 专利/商标/版权排查
- [ ] 认证与平台类目政策确认
- [ ] 至少 2 家供应商、打样确认
- [ ] 首批库存与现金流压力测试
